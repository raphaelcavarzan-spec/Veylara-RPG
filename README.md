# Veylara RPG

RPG 2D de fantasia medieval para PC, baseado na campanha original de Veylara.

## Visão do projeto

- **Motor planejado:** Godot 4.x
- **Linguagem:** GDScript
- **Perspectiva:** 2D com visão de cima
- **Primeira região jogável:** Brumavale
- **Primeiro personagem jogável:** Isildur
- **Plataforma-alvo inicial:** Windows PC

## Direção visual

A imagem aprovada de Brumavale e a ficha aprovada de Isildur são as referências visuais do projeto. Não substituir por versões genéricas sem autorização. A ilustração de Brumavale será usada como referência/base visual, com camadas de gameplay, colisões, profundidade e elementos interativos construídos separadamente.

## Primeiro marco jogável

1. Criar e abrir o projeto no Godot.
2. Implementar movimento de Isildur para norte, sul, leste e oeste.
3. Implementar colisões e ordenação de profundidade.
4. Criar uma área explorável baseada em Brumavale.
5. Testar o protótipo antes de considerar o marco concluído.

## Princípios de desenvolvimento

- A campanha original é a fonte de verdade para o cânone.
- Marcar informações narrativas não confirmadas como **PENDENTE DE CONFIRMAÇÃO**.
- Não antecipar segredos ou revelações futuras.
- Manter protótipos separados do conteúdo aprovado.
- Não declarar um sistema concluído sem testá-lo.
- Registrar decisões, pendências e resultados dos testes.
